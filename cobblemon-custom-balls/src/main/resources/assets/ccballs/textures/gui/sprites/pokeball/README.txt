Aca va el sprite que se muestra en la "barra lateral" (HUD de captura / lista de balls
durante la pelea). Cobblemon suele usar un PNG chico por ball para este HUD; el nombre
de archivo esperado depende de tu version - si no encontras donde lo lee, busca en el
jar de Cobblemon la carpeta assets/cobblemon/textures/gui/... y segui el mismo patron
de nombre para tu namespace "ccballs".
